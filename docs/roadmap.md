# Roadmap

## Phase 1 — Technical foundation (current focus)

**Goal:** One reusable, observable architecture.

- Choose and set up n8n (self-hosted preference for control)
- Multi-LLM access (Grok + at least one more)
- PostgreSQL / Supabase for structured data and basic multi-tenancy patterns
- Basic cost tracking and logging per workflow
- Simple client interface approach (chat + reports)
- Standard patterns for credentials, approvals, error handling

**Deliverable:** Working reusable stack that can support the first 5 solutions.

---

## Phase 2 — Productise 5 standardized solutions

1. Email & calendar / administrative assistant
2. Invoice & receipt processing assistant
3. Sales & quotation assistant
4. Customer support assistant
5. Reporting & management assistant

Each must have:
- Clear workflow
- Cost estimate
- Implementation checklist
- KPI definitions
- Risk / human approval rules

**Deliverable:** Small, sellable product catalogue.

---

## Phase 3 — Validate with 3–5 real SMEs

- Choose clients with different processes but realistic data readiness
- Measure baseline (hours, response times, error rates, volume)
- Run pilots
- Capture real costs, intervention rates, actual value delivered
- Turn results into case studies and refined pricing

**Deliverable:** Real evidence + validated commercial model.

---

## Phase 4 — Standardize and scale

- Reusable integration modules
- Deployment templates
- Onboarding playbooks
- Subscription & usage management
- Monitoring and support processes
- Aim for 70-90% architectural reuse

**Deliverable:** A repeatable AI integration / operations business, not pure custom consulting.
