# Market Opportunity & Decision Framework

## The real opportunity

Not "selling AI".  
Selling **improvements to existing business operations** through agents, integrations, automation and managed infrastructure.

Customers pay for:
- More sales / better conversion
- Fewer administrative hours
- Faster customer response
- Fewer errors
- Better reporting and visibility
- Lower operating friction

---

## Dependency framework (when is an implementation worthwhile?)

| Dimension              | What to measure                          | Why it matters                     |
|------------------------|------------------------------------------|------------------------------------|
| Work volume            | Tasks per month                          | Potential savings scale            |
| Task complexity        | Steps per task                           | Agent + integration complexity     |
| Labour cost            | Fully loaded hourly cost                 | Financial benefit                  |
| Data quality           | Completeness, consistency, accessibility | Reliability of the system          |
| Software ecosystem     | Number and type of systems               | Integration cost & risk            |
| Automation suitability | Repetitive vs judgement-heavy            | Realistic automation rate          |
| Risk                   | Financial, legal, reputational           | Approval & control requirements    |
| Adoption               | Employee usage and acceptance            | Realized vs theoretical value      |

### Integration difficulty (we price and select accordingly)

Level 1: Native connector  
Level 2: Standard API  
Level 3: API + auth + mapping  
Level 4: Legacy / custom  
Level 5: No API (files / RPA)

Early clients should mostly be Level 1-3.

### Human intervention

We measure % of tasks completed without human intervention, but we never optimize this at the expense of accuracy. A safe 75% is better than an inaccurate 95%.

---

## Scoring opportunities

Proposed prioritization formula (0-100 each variable):

Value × Frequency × Suitability × Integration simplicity × Data readiness × Controllable risk

Highest scores get investigated first.

---

## What we measure after deployment (client dashboard)

- Hours saved / capacity gained
- Tasks completed per employee
- Lead response time & conversion
- Average resolution / response time
- Error / rework rate
- Invoice processing time
- Cost per successful task
- Human intervention rate
- Success rate of agents

We always separate cash savings vs capacity vs revenue vs risk reduction when talking to clients.
