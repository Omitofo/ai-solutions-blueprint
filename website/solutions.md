## How we price

We do not simply mark up token costs.

We calculate:
1. Implementation effort
2. Monthly infrastructure + maintenance + support allocation
3. Expected value for the client (hours, revenue, risk reduction)

Then we only recommend a package when the client can see a clear positive case (ideally payback in a few months).

Exact pricing is confirmed after discovery, once we understand volume, systems and complexity.
