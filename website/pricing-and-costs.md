**Key insight for clients:**  
The pure cost of tokens is frequently only a fraction of the total. The real ongoing cost is keeping the system reliable, integrated and supported.

## 3. Understanding token costs (simple explanation)

Every time an agent reads information or generates a response it consumes **tokens** (pieces of text).

Rough mental model:

- Input tokens = what the model reads (email, documents, context, instructions)
- Output tokens = what the model writes (drafts, summaries, structured data)

**Illustrative example** (order of magnitude only):

Imagine an email assistant that processes 1,000 emails per month.

- Average ~4,000 input tokens + 500 output tokens per email
- Using a modern model priced around a few dollars per million tokens

The pure model cost for that volume can easily stay in the **low tens of euros per month**.

If the agent does more complex reasoning, multiple steps, retrieval or retries, the number goes up — but it is still usually modest compared with the value of the hours saved.

We measure real usage in production and can show clients cost-per-task once the system is running.

### Scenario B — Construction company (20 people)

- Estimated internal operating cost range: €350–900 / month
- Typical client investment: ~€600–1,200 / month + setup

### Scenario C — Distribution company (60 people)
- Multiple specialised agents across sales, service, finance and management
- Estimated internal operating cost range: €1,200–3,500 / month
- Typical client investment: €2,000–5,000 / month + higher setup

These are planning scenarios, not quotations. Real numbers depend on volume, number of systems and complexity of integrations.
