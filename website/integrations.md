## How integration difficulty affects the project

Not all systems are equal:

| Level | Type of integration                     | Impact on project          |
|-------|-----------------------------------------|----------------------------|
| 1     | Native / ready-made connector           | Fast and low risk          |
| 2     | Standard API                            | Straightforward            |
| 3     | API + authentication + custom mapping   | Medium effort              |
| 4     | Legacy or complex custom API            | Higher effort & cost       |
| 5     | No API (files or desktop automation)    | Highest complexity         |

During discovery we classify every system. This keeps both scope and pricing realistic.

## Our approach

1. **Discover** — map processes, tools, volumes and pain points
2. **Design** — select the right agents and integration path
3. **Implement** — connect systems, build workflows, add human approval points where needed
4. **Measure** — track cost per task, hours saved, intervention rate and business results
5. **Manage** — we keep the system running, updated and under control

You keep ownership of your data and your tools. We provide the intelligent layer that makes them work harder for you.
