# 05 — How it looks in real work

## Intent
Make the abstract concrete through recognisable scenes.

## Scenes we will visualise

1. **Email & communication**  
   Agent reads, classifies, drafts replies, organises attachments.

2. **Quotations**  
   Agent prepares a quotation from templates + price list and asks for approval.

3. **Invoices & receipts**  
   Agent extracts data, categorises, detects duplicates, prepares for accounting.

4. **Daily / weekly reporting**  
   Clean summary ready for the manager without manual compilation.

5. **Lead follow-up**  
   Automatic, consistent follow-up sequences.

## Layout
Horizontal or stacked visual scenes with very short labels + one outcome line each.

## Visual assets needed
One scene illustration per use case (R01–R05 in the master list).
