# 02 — Ride the wave

## Intent
Create soft urgency + forward energy.

Visitor feeling:  
“I don’t want to be left behind. I want to get on this.”

## Copy direction

**Headline:**  
Don’t get left behind.

**Supporting line:**  
Integrate intelligent systems and ride the wave of the future.

Optional second line:  
The businesses that start building these systems now are already moving differently.

## Layout
- Full-width statement block
- Strong short headline
- One clean supporting sentence
- Minimal visual of forward motion / wave / rising path of light
- Still white AI Lab aesthetic
- Lots of space

1. Full-width statement section visual (headline + subtle motion graphic or abstract wave)
