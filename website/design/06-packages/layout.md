# 06 — Packages (quietly presented)

## Intent
Show that clear options exist, without turning the page into a pricing hard-sell.

## Marketing role
Structure and choice. The visitor understands there is a path that fits different stages.

## Layout
Classic 3-column cards, generous spacing, outcome-first language.

**Office Assistant** → for smaller teams  
**Business Operations** → for growing SMEs  
**Business Infrastructure** → for more complex needs

## Copy style
- Name of package
- One sentence of who it is for
- 3 short outcome bullets (not feature lists)
- Soft button

Prices can appear, but they should not dominate the section.
