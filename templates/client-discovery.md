# Client Discovery Checklist

Use this in every first serious conversation / discovery workshop.

## 1. Company basics
- [ ] Industry / activity
- [ ] Number of employees / main roles
- [ ] Current tools (email, CRM, accounting, ERP, documents, messaging)
- [ ] Approximate volume of key processes (emails/day, invoices/month, quotations/month, support tickets, etc.)

## 2. Pain & priorities
- [ ] What takes the most administrative time?
- [ ] Where do delays or errors hurt the most?
- [ ] What would "success" look like in 3-6 months?
- [ ] Who feels the pain (owner, ops, sales, admin)?

## 3. Data & systems readiness
- [ ] Are documents mostly digital?
- [ ] Are processes standardized or highly variable?
- [ ] Do the main tools have usable APIs / connectors?
- [ ] Is customer / supplier data clean or heavily duplicated?
- [ ] Any sensitive / regulated data involved?

## 4. Economics (rough)
- [ ] Approximate loaded cost per hour of the people doing the work
- [ ] Current time spent on candidate processes
- [ ] Any measurable revenue impact (response time → conversion, etc.)

## 5. Risk & governance
- [ ] Which actions can never be fully automated?
- [ ] Who must approve what?
- [ ] Existing compliance or quality requirements

## 6. Next step decision
- [ ] Is there a clear high-value, feasible first process?
- [ ] Rough order of magnitude of value vs cost
- [ ] Willingness to run a limited pilot
- [ ] Decision maker and timeline

**Output of discovery:**  
Go / No-go recommendation + recommended package or pilot scope + high-level business case.
